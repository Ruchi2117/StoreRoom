Scope, honestly stated.

The current model supports Red Bull, Knoppers Riegel, Valser Classic, Valser Still and Capri-Sun Multivitamin. Independent field generalization is unverified. Expanded Indian retail recognition is at the dataset-audit stage.

This local demo uses a shared customer identity. No authentication, payments, delivery or multi-shop location matching. Accepted reservations currently have no fulfillment/release workflow.
